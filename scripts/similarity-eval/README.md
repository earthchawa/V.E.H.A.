# ประเมินความแม่นยำของการตรวจความคล้าย (ชุดข้อมูลทดสอบ)

สคริปต์สำหรับการทดลองในหัวข้อ 4.2 ของบทความ ใช้ชุดข้อมูลจำลองเท่านั้น — **ห้ามใส่งานจริงของ นนอ.**

| ไฟล์ | หน้าที่ |
|---|---|
| `make-variants.mjs` | สร้างงานคัดลอกระดับ L0–L3 จากต้นฉบับ (กฎตายตัว + seed) และไฟล์ `pairs.csv` |
| `run-web.cjs` | ทำการทดลองผ่านหน้าเว็บจริง: สร้างบัญชีทดสอบ วิชาทดสอบ งาน 4 งาน ส่งงาน และอ่านค่าความคล้ายทุกคู่ (เปิด/ปิด "ไม่นับข้อความที่พบในงานส่วนใหญ่") |
| `evaluate.mjs` | คำนวณ Precision / Recall / F1 จาก `scores.csv` → `results.md` |

## โครงสร้างชุดข้อมูล

เก็บไว้นอก repo หรือในโฟลเดอร์ `data/` ของที่นี่ (ถูก gitignore)

```
<dataset>/originals/T1_H1.txt, T1_A1.txt, …, P2_A2.py   ← ต้นฉบับ (H = คนเขียน, A = AI)
<dataset>/l4/T1_H1_L4.txt, …                            ← งานเรียบเรียงใหม่ระดับ L4 (ไม่บังคับ)
```

## ขั้นตอน

1. สร้างงานดัดแปลงและรายการคู่

```bash
node scripts/similarity-eval/make-variants.mjs <dataset>
```

2. ติดตั้ง Playwright บนเครื่องที่จะรัน (ครั้งแรกครั้งเดียว)

```bash
npm install --no-save playwright && npx playwright install chromium
```

3. รันกับเว็บ (ตัวอย่างนี้คือเว็บจริง ใส่รหัสผ่านผู้ดูแลระบบเป็นตัวแปร ไม่ต้องเขียนลงไฟล์)

```bash
VEHA_URL="https://veha-nkrafa.vercel.app" VEHA_ADMIN_PASSWORD="…" EXP_YEAR=2569 EXP_SEMESTER=2 node scripts/similarity-eval/run-web.cjs <dataset>
```

4. คำนวณผล

```bash
node scripts/similarity-eval/evaluate.mjs <dataset>/web-run/scores.csv
```

## ตัวแปร

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `VEHA_URL` | `http://localhost:3000` | เว็บที่จะทดสอบ |
| `VEHA_ADMIN_USER` / `VEHA_ADMIN_PASSWORD` | `admin` / — | บัญชีผู้ดูแลระบบ (รหัสผ่านปัจจุบัน) |
| `EXP_PREFIX` | `simtest` | ชื่อบัญชีทดสอบ: `simtest-t` (อาจารย์), `simtest01`… (นนอ. ทดสอบ) |
| `EXP_COURSE` | `SIM901` | รหัสวิชาทดสอบ |
| `EXP_YEAR` / `EXP_SEMESTER` | `2569` / `1` | ภาคเรียนของวิชาทดสอบ — ควรใช้ภาคที่มีอยู่แล้ว ถ้ายังไม่มีระบบจะสร้างภาคใหม่ |

## ผลลัพธ์ (`<dataset>/web-run/`)

`scores.csv` (ค่าความคล้ายรายคู่), `results.md`, `mapping.csv` (ไฟล์ไหนส่งด้วยบัญชีใด), `run-log.txt`
(เวลาของทุกขั้นตอน), ภาพหน้าจอ `*.png` (ใช้เป็นหลักฐาน/ภาพประกอบบทความ) และ `credentials.json`
(รหัสผ่านบัญชีทดสอบ — เก็บเป็นความลับ อย่า commit)

## สิ่งที่ค้างอยู่บนเว็บหลังรัน

- บัญชี `simtest-t`, `simtest01`… ลบไม่ได้ ปิดการใช้งานได้ที่ ผู้ดูแลระบบ → ผู้ใช้
- วิชา `SIM901` กลุ่ม 1 พร้อมงานที่ส่ง ลบกลุ่มเรียนได้ที่ ผู้ดูแลระบบ → รายวิชา
- บันทึกการใช้งาน (audit log) ของการสร้างบัญชี การเข้าสู่ระบบ และการส่งงาน — เป็นหลักฐานเวลาที่ทดลองจริง
- รันซ้ำได้: ใช้บัญชี วิชา และงานเดิม แล้วส่งไฟล์ใหม่ทับ
