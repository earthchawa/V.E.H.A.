## 1. เข้าสู่ระบบครั้งแรก

1. เปิดเว็บไซต์ของระบบ (ขอที่อยู่จากอาจารย์หรือผู้ดูแลระบบ)
2. ช่อง **Username หรือ ID**: ใส่**เลขประจำตัว นนอ.** ของตัวเอง
3. ช่อง **รหัสผ่าน**: ใส่รหัสผ่านเริ่มต้นที่ได้รับแจก แล้วกด **เข้าสู่ระบบ**
4. ระบบให้**ตั้งรหัสผ่านใหม่**ทันที ก่อนใช้งานส่วนอื่น
   - อย่างน้อย 8 ตัว มีทั้งตัวอักษรภาษาอังกฤษและตัวเลข
   - ห้ามมีเลขประจำตัวของตัวเองอยู่ในรหัสผ่าน
5. กด **บันทึกรหัสผ่าน** แล้วระบบจะพาไปหน้าแรก

> ⚠️ รหัสผ่านเริ่มต้น**หมดอายุใน 14 วัน** ถ้าไม่ได้เข้าระบบภายในเวลานั้น ต้องขอรหัสใหม่จากผู้ดูแลระบบ
>
> ⚠️ ใส่รหัสผิด **5 ครั้งติดกัน** บัญชีจะถูกล็อก 15 นาที

**ลืมรหัสผ่าน:** กด **ลืมรหัสผ่าน?** ระบบจะแจ้งให้**ติดต่อผู้ดูแลระบบ** ซึ่งจะออกรหัสผ่านชั่วคราวใหม่ให้ (แล้วต้องตั้งรหัสใหม่อีกครั้งเมื่อเข้าระบบ)

**ปุ่มมุมขวาบน:** สลับภาษา **TH / EN** และธีม **มืด / สว่าง** ได้ทุกหน้า ระบบจำค่าที่เลือกไว้

## 2. หน้าแรก

หน้าแรกมี 2 ส่วน

| ส่วน | แสดงอะไร |
|---|---|
| **สำหรับคุณ** | งานที่ยังไม่ส่งและแบบทดสอบที่เปิดอยู่ ในทุกวิชา เรียงตามกำหนดส่ง กดเพื่อไปที่งานนั้นได้ทันที |
| **รายวิชาของฉัน** | การ์ดวิชาที่ลงทะเบียนในภาคเรียนนี้ จัดกลุ่มตามภาควิชา |

- ปุ่มภาคเรียนด้านบนใช้**ดูภาคเรียนก่อนหน้า** งานและคะแนนของภาคเก่ายังอยู่ครบ
- เห็นเฉพาะวิชาที่ลงทะเบียนไว้ ถ้าวิชาไหนหายไป ให้แจ้งอาจารย์ผู้สอนหรือผู้ดูแลระบบ

**บนมือถือ:** เมนูด้านบนยุบเป็นปุ่ม **เมนู** (☰)

## 3. ห้องเรียน

กดการ์ดวิชาเพื่อเข้าห้องเรียน มี 4 แท็บ

| แท็บ | ใช้ทำอะไร |
|---|---|
| **เอกสาร** | ดาวน์โหลดเอกสารและเปิดลิงก์ที่อาจารย์ให้ |
| **งานที่มอบหมาย** | อ่านคำสั่งงาน ส่งงาน ดูรายงานความคล้าย |
| **แบบทดสอบ** | ทำแบบทดสอบ ดูผลสอบ |
| **คะแนน** | ดูคะแนนของตัวเอง |

ปุ่ม **ย้อนกลับ** ใต้แท็บพาไปหน้าก่อนหน้า

## 4. เอกสาร

- เอกสารจัดกลุ่มตาม**สัปดาห์**
- กดชื่อไฟล์เพื่อดาวน์โหลด หรือกดลิงก์เพื่อเปิด (เช่น YouTube, Google Drive)

## 5. ส่งงาน

1. แท็บ **งานที่มอบหมาย** → กดชื่องาน
2. อ่าน **คำสั่งงาน** และ **กำหนดส่ง** (เวลาประเทศไทย)
3. ในส่วน **งานของคุณ**
   - พิมพ์คำตอบในช่อง **คำตอบ** และ/หรือ
   - แนบไฟล์ใน **ไฟล์แนบ** (ลากไฟล์มาวาง หรือคลิกเพื่อเลือก) ไม่เกิน 5 ไฟล์
4. กด **ส่งงาน**

**ส่งใหม่:** ส่งได้หลายครั้งจนกว่าจะปิดรับ กด **ส่งใหม่** ระบบเก็บเฉพาะครั้งล่าสุด (แสดงเป็น "ครั้งที่ N") ถ้าไม่เลือกไฟล์ใหม่ ระบบใช้ไฟล์เดิม

**สถานะงาน**

| สถานะ | ความหมาย |
|---|---|
| ยังไม่ส่ง | ยังไม่ถึงกำหนดและยังไม่ได้ส่ง |
| ส่งแล้ว | ส่งก่อนกำหนด |
| ส่งช้า | ส่งหลังกำหนด (เฉพาะงานที่อาจารย์เปิดรับงานส่งช้า) |
| ไม่ได้ส่ง | เลยกำหนดแล้วและอาจารย์ไม่รับงานส่งช้า |
| ปิดรับงานแล้ว | ส่งหรือแก้ไม่ได้อีก |

**คำแนะนำเรื่องไฟล์**
- ระบบตรวจความคล้ายได้กับ: ข้อความ, โค้ด (.py .java .c .js …), PDF, Word (.docx), Jupyter (.ipynb)
- **งานภาษาไทย:** แนะนำให้พิมพ์ในช่องคำตอบหรือส่งเป็น .docx เพราะ PDF ภาษาไทยบางไฟล์ดึงข้อความออกมาได้ไม่ถูกต้อง (ระบบจะแสดงว่า "ไม่ได้ตรวจ")

## 6. รายงานความคล้าย

ถ้าอาจารย์เปิดให้ดู จะมีปุ่ม **ดูรายงานความคล้าย** ในหน้างาน (บางงานดูได้หลังกำหนดส่งเท่านั้น)

- **ความคล้ายรวม:** สัดส่วนของงานที่พบซ้ำกับแหล่งอื่น แยกเป็น 3 ช่อง: **เพื่อนในวิชา / งานรุ่นก่อน / เอกสารอ้างอิง**
- ส่วนที่ซ้ำแสดงเป็น**ไฮไลต์**ในงานของคุณ
- แหล่งที่ตรงกันแสดงเป็น "งานของเพื่อน #1, #2" **คุณไม่เห็นชื่อหรือเนื้อหางานของคนอื่น** และเพื่อนก็ไม่เห็นของคุณเช่นกัน

| ระดับ | ความคล้าย |
|---|---|
| ต่ำ | น้อยกว่า 15% |
| ปานกลาง | 15–40% |
| สูง | 40% ขึ้นไป |

> ความคล้ายเป็น**สัญญาณให้อาจารย์ตรวจสอบ ไม่ใช่คำตัดสินว่าทุจริต** ข้อความตั้งต้นที่อาจารย์ให้ทุกคนใช้ และประโยคที่ทั้งชั้นใช้เหมือนกัน (เช่น คัดลอกโจทย์) ระบบไม่นับอยู่แล้ว

## 7. ทำแบบทดสอบ

### ก่อนสอบ
- ใช้โน้ตบุ๊กที่ชาร์จแบตเต็มและเชื่อมต่ออินเทอร์เน็ตได้
- ใช้ Chrome, Edge หรือ Firefox รุ่นล่าสุด
- ปิดโปรแกรมและแท็บอื่น

### ระหว่างสอบ
1. แท็บ **แบบทดสอบ** → กดชื่อแบบทดสอบ → **เริ่มทำแบบทดสอบ**
2. ระบบเปิด**โหมดเต็มจอ** มุมบนแสดง **เวลาที่เหลือ** และจำนวนข้อที่ **ตอบแล้ว**
3. ตอบคำถาม ระบบ**บันทึกให้อัตโนมัติ** (มีคำว่า "บันทึกแล้ว")
4. เสร็จแล้วกด **ส่งคำตอบ** → ยืนยัน (ส่งแล้วแก้ไม่ได้)
5. **หมดเวลา ระบบส่งให้อัตโนมัติ**

**ชนิดคำถาม**

| ชนิด | วิธีตอบ |
|---|---|
| ปรนัย (ตอบข้อเดียว) | เลือก 1 ตัวเลือก |
| ปรนัย (ตอบได้หลายข้อ) | เลือกทุกข้อที่ถูก (เลือกผิดถูกหักคะแนนในข้อนั้น แต่ไม่ติดลบ) |
| คำตอบสั้น | พิมพ์คำตอบ |
| อัตนัย | พิมพ์คำตอบยาว |
| เขียนโค้ด | เขียนโค้ดในช่อง editor แล้วกด **รัน** (หรือ **รันและดูผล** สำหรับ HTML) เพื่อทดสอบ โค้ดรันในเบราว์เซอร์ของคุณ รันได้ครั้งละไม่เกิน 10 วินาที ข้อสอบ Python ใส่ข้อมูลสำหรับ `input()` ได้ที่ **ข้อมูลเข้าสำหรับ input()** |

### สิ่งที่ระบบบันทึกให้อาจารย์เห็น
- ออกจากหน้าต่างหรือสลับแท็บ
- ออกจากโหมดเต็มจอ (กดปุ่ม **กลับเข้าโหมดเต็มจอ** เพื่อกลับ)
- พยายามคัดลอก วาง หรือคลิกขวา (ระบบบล็อกไว้)
- โหลดหน้าใหม่ หรือทำต่อจากเครื่องหรือเครือข่ายอื่น

> การสอบมีอาจารย์คุมสอบในห้อง ระบบเป็นเพียงเครื่องมือช่วยบันทึก

### ถ้าเกิดปัญหาระหว่างสอบ
- **เน็ตหลุด / เผลอปิดหน้า:** เปิดแบบทดสอบอีกครั้งแล้วกด **ทำต่อ** คำตอบที่บันทึกแล้วยังอยู่ แต่**เวลายังเดินต่อ**
- **เครื่องเสีย:** แจ้งอาจารย์คุมสอบทันที อาจารย์ให้ทำใหม่ได้
- บางแบบทดสอบ**ทำได้เฉพาะในห้องสอบ** ถ้าเริ่มไม่ได้ ให้ตรวจว่าเชื่อมต่อ Wi-Fi ของห้องสอบ

### ผลสอบ
ขึ้นกับที่อาจารย์ตั้งไว้ หลังปิดสอบจะเห็น: ไม่เห็นอะไร / คะแนนของตัวเอง / คะแนน คำตอบ และความเห็นจากอาจารย์ ข้ออัตนัยและข้อเขียนโค้ดต้องรออาจารย์ตรวจก่อน

## 8. ดูคะแนน

แท็บ **คะแนน** (หัวข้อ "คะแนนของฉัน")

- เห็นเฉพาะรายการที่อาจารย์**เผยแพร่แล้ว** พร้อม **ความเห็นจากอาจารย์**
- รายการที่ยังไม่ตรวจแสดงว่า "ยังไม่ให้คะแนน"
- **เกรดปัจจุบัน** คิดจากรายการที่เผยแพร่และให้คะแนนแล้วเท่านั้น จึงอาจเปลี่ยนเมื่อมีคะแนนเพิ่ม (บางวิชาอาจารย์ไม่เปิดให้ดูคะแนนรวม)
- เห็นเฉพาะคะแนนของตัวเอง

---

## 9. บัญชีของฉัน

กดชื่อของตัวเองที่มุมขวาบน → **บัญชีของฉัน**

- **เปลี่ยนรหัสผ่าน:** ใส่รหัสผ่านปัจจุบันและรหัสใหม่ เมื่อเปลี่ยนแล้ว อุปกรณ์อื่นที่เข้าระบบค้างไว้จะถูกออกจากระบบ
- **อีเมลกู้รหัสผ่าน:** ใส่ไว้สำหรับอนาคต (ตอนนี้การรีเซ็ตรหัสผ่านทำผ่านผู้ดูแลระบบ)
- **ออกจากระบบ** ทุกครั้งเมื่อใช้เครื่องสาธารณะ

## 10. คำถามที่พบบ่อย

**ถาม: เข้าระบบไม่ได้ ขึ้นว่า "รหัสผ่านเริ่มต้นหมดอายุ"**
ตอบ: ติดต่อผู้ดูแลระบบเพื่อขอรหัสผ่านชั่วคราวใหม่

**ถาม: ส่งไฟล์ไม่ได้ ขึ้นว่าไฟล์ใหญ่เกินไป**
ตอบ: ลดขนาดไฟล์ (เช่น บีบอัดรูป หรือ export PDF ใหม่) หรือแบ่งเป็นหลายไฟล์ ขนาดที่ส่งได้แสดงไว้ใต้ช่องไฟล์แนบ

**ถาม: ส่งงานแล้ว แต่อยากแก้**
ตอบ: กด **ส่งใหม่** ได้จนกว่าจะปิดรับ ระบบเก็บครั้งล่าสุด

**ถาม: ความคล้ายสูง แต่ไม่ได้ลอกใคร**
ตอบ: ความคล้ายเป็นเพียงสัญญาณ อาจารย์จะดูไฮไลต์ก่อนตัดสินเสมอ เช่น ประโยคนิยามจากตำราอาจตรงกับเพื่อนโดยบังเอิญ ถ้ามีข้อสงสัยให้คุยกับอาจารย์ผู้สอน

**ถาม: ไม่เห็นวิชาที่เรียนอยู่**
ตอบ: แจ้งผู้ดูแลระบบให้เพิ่มรายชื่อในกลุ่มเรียน หรือตรวจว่าเลือกภาคเรียนถูกต้อง

**ถาม: ไม่เห็นคะแนน**
ตอบ: อาจารย์ยังไม่ได้เผยแพร่รายการนั้น
