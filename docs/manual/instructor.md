## 1. หน้าแรกและงานที่ต้องจัดการ

| ส่วน | แสดงอะไร |
|---|---|
| **สำหรับคุณ / งานที่ต้องจัดการ** | รวมทุกวิชาที่สอนในภาคนี้: งานที่ **รอให้คะแนน**, งานที่ **ความคล้ายสูง** (≥ 40%), งานที่ใกล้ถึงกำหนดภายใน 7 วันพร้อมจำนวนที่ส่งแล้ว, แบบทดสอบที่เปิดอยู่ และ **คำตอบรอตรวจ** |
| **รายวิชาของฉัน** | การ์ดวิชาที่สอน จัดตามภาควิชา |
| **ภาคเรียนถัดไป** | ถ้าผู้ดูแลระบบเปิดวิชาของภาคหน้าไว้แล้ว จะมีแถบแจ้งพร้อมปุ่ม **เตรียมเนื้อหาล่วงหน้า** เพื่อเพิ่มเอกสารและงานไว้ก่อนเปิดภาค |

> วิชาที่สอน**ผู้ดูแลระบบเป็นผู้กำหนด** (ผ่านการนำเข้าตารางสอนหรือ "จัดการรายชื่อ") ถ้าวิชาไหนไม่ขึ้น ให้แจ้งผู้ดูแลระบบ

## 2. ห้องเรียนและกลุ่มเรียน

- ห้องเรียน 1 ห้อง = รายวิชา 1 กลุ่มเรียนในภาคเรียนหนึ่ง (เช่น CS231 กลุ่ม 1 ภาค 1/2569)
- แต่ละกลุ่มเรียนมีเอกสาร งาน แบบทดสอบ และสมุดคะแนนของตัวเอง ถ้าสอนหลายกลุ่ม ดูวิธีคัดลอกใน [ข้อ 11](#11-สอนหลายกลุ่มเรียน)
- แท็บในห้องเรียน: **เอกสาร | งานที่มอบหมาย | แบบทดสอบ | คะแนน**
- ทุกปุ่ม "สร้าง/แก้ไข" เปิดเป็นหน้าต่าง popup กด Esc หรือคลิกนอกหน้าต่างเพื่อปิด เมื่อบันทึกสำเร็จ หน้าต่างจะปิดและมีข้อความยืนยันขึ้นที่ด้านล่างจอ
- การตั้งค่าแบบเปิด/ปิด (เช่น **ให้ นนอ. เห็น**, **รับงานส่งช้า**) เป็น**สวิตช์** สีน้ำเงิน = เปิด
- การลบทุกอย่างมีหน้าต่างถามยืนยันก่อน
- ไอคอน **ⓘ** ข้างหัวข้อ: วางเมาส์หรือแตะเพื่อดูคำอธิบาย

## 3. เอกสาร

1. แท็บ **เอกสาร** → **เพิ่มเอกสาร**
2. เลือก **อัปโหลดไฟล์** (ลากไฟล์มาวางได้) หรือ **แปะลิงก์** (YouTube, Google Drive ฯลฯ)
3. ใส่ **ชื่อเอกสาร**, **สัปดาห์** (เว้นว่าง = ทั่วไป), **คำอธิบาย**
4. เปิดสวิตช์ **ให้ นนอ. เห็น** ถ้าต้องการเผยแพร่ทันที (ปิด = เก็บเป็นร่าง)

- แต่ละรายการมีสวิตช์ **ให้ นนอ. เห็น** ไว้ซ่อนหรือเผยแพร่ภายหลัง นนอ. ไม่เห็นและดาวน์โหลดเอกสารที่ซ่อนไม่ได้
- ขนาดไฟล์สูงสุดแสดงในฟอร์ม (เซิร์ฟเวอร์ของสถาบัน 50 MB)

## 4. งานที่มอบหมาย

### 4.1 สร้างงาน

แท็บ **งานที่มอบหมาย** → **สร้างงานใหม่**

| ช่อง | คำอธิบาย |
|---|---|
| ชื่องาน / คำสั่งงาน | |
| กำหนดส่ง | เวลาประเทศไทย เว้นว่างได้ถ้าไม่มีกำหนดส่ง |
| รับงานส่งช้า | เปิด = ส่งหลังกำหนดได้แต่ถูกทำเครื่องหมาย "ส่งช้า" |
| ให้ นนอ. เห็น | ปิด = ฉบับร่าง |
| คะแนนเต็ม / หมวดคะแนน | ใส่เพื่อเพิ่มงานเป็นคอลัมน์ในสมุดคะแนนอัตโนมัติ |
| **ตรวจความคล้ายระหว่างงานที่ส่ง** | เปิดไว้เป็นค่าเริ่มต้น ตัวเลือก 3 ข้อด้านล่างอยู่ในกรอบเดียวกัน และจะซ่อนเมื่อปิดสวิตช์นี้ (ค่าที่ตั้งไว้ยังอยู่) |
| ↳ ไม่นับข้อความที่ซ้ำกันเกินครึ่งชั้น | ตัดประโยคจากตำราหรือโจทย์ที่ทุกคนคัดลอก (ทำงานเมื่อมีงานส่ง ≥ 4 ชิ้น) |
| ↳ นนอ. ดูรายงานของตัวเองได้ | **ทันที / หลังกำหนดส่ง / ไม่ให้ดู (เฉพาะอาจารย์)** |
| ↳ ข้อความตั้งต้นที่ไม่นับ | โจทย์หรือโค้ดตั้งต้นที่ทุกคนต้องมีเหมือนกัน ส่วนนี้ไม่ถูกนับเป็นความคล้าย |

### 4.2 ติดตามงานที่ส่ง

แท็บ **งานที่มอบหมาย** แสดงงานเป็นการ์ด แต่ละการ์ดบอกจำนวนที่ส่งแล้ว (เช่น ส่งแล้ว 3/5 พร้อมแถบความคืบหน้า) กดที่ใดก็ได้บนการ์ดหรือปุ่ม **งานที่ส่ง ›** เพื่อเปิดงาน

หน้างานแสดงตาราง **งานที่ส่ง**: ชื่อ นนอ., เวลาส่ง, สถานะ (ส่งแล้ว / ส่งช้า / ยังไม่ส่ง), **ความคล้าย**, คะแนน และลิงก์ **รายงาน** เรียงตามความคล้ายจากมากไปน้อย

- **แก้ไขงาน** / **ลบงาน** (ลบแล้วงานที่ส่งหายทั้งหมด ย้อนกลับไม่ได้)
- ดาวน์โหลดไฟล์ที่ นนอ. ส่งได้จากหน้ารายงาน

## 5. ตรวจความคล้าย

### 5.1 หน้ารายงานของ นนอ. แต่ละคน

กด **รายงาน** ในตารางงานที่ส่ง

- **ความคล้ายรวม** และแยก 3 ช่อง: **เพื่อนในวิชา / งานรุ่นก่อน / เอกสารอ้างอิง** (ข้อความหนึ่งอาจตรงหลายแหล่ง ผลรวมจึงอาจเกินตัวเลขรวม)
- เนื้อหางานพร้อม**ไฮไลต์**ส่วนที่ซ้ำ สีตามแหล่ง และรายการแหล่งที่ตรงกัน (อาจารย์เห็นชื่อเพื่อน แต่งานรุ่นก่อนเป็นนิรนามเสมอ)
- ส่วน **ให้คะแนน**: ใส่คะแนนและความเห็นได้ในหน้าเดียวกัน (ถ้างานมีคะแนนเต็ม)

### 5.2 เทียบสองชิ้น

ในหน้างาน ส่วน **คู่ที่คล้ายกันมากที่สุด** → กด **เทียบ** เพื่อเปิดงานสองชิ้นข้างกันพร้อมไฮไลต์ส่วนที่ตรงกัน

### 5.3 ตรวจใหม่

กด **ตรวจใหม่** หลังแก้ข้อความตั้งต้นหรือตัวเลือก "ไม่นับข้อความที่ซ้ำกันเกินครึ่งชั้น"

### 5.4 การแปลผล

| ระดับ | ความคล้าย | ควรทำ |
|---|---|---|
| ต่ำ | < 15% | ปกติ |
| ปานกลาง | 15–40% | ดูไฮไลต์ว่าเป็นนิยาม โจทย์ หรือการลอก |
| สูง | ≥ 40% | เปิดเทียบสองชิ้น แล้วคุยกับ นนอ. |

> ⚠️ ความคล้ายเป็น**สัญญาณให้ตรวจสอบ ไม่ใช่หลักฐานการทุจริต** ควรดูไฮไลต์ก่อนตัดสินทุกครั้ง
>
> **โค้ด:** ระบบไม่สนชื่อตัวแปร ค่าคงที่ และคอมเมนต์ จึงจับงานที่แค่เปลี่ยนชื่อตัวแปรได้ แต่โจทย์สั้นๆ ที่มีวิธีเขียนไม่กี่แบบอาจคล้ายกันโดยธรรมชาติ
>
> **ยังตรวจไม่ได้:** หน้าเว็บที่ไม่ได้เพิ่มไว้ในคลัง และงานที่เขียนด้วย AI

## 6. คลังแหล่งอ้างอิง

ในหน้างาน การ์ด **คลังแหล่งอ้างอิง** ใช้เพิ่มแหล่งให้ระบบตรวจเทียบนอกเหนือจากเพื่อนในชั้น

| ปุ่ม | ใช้เมื่อ |
|---|---|
| **งานรุ่นก่อน** | เลือกงานเดียวกันจากภาคเรียนก่อนหรือกลุ่มเรียนอื่น งานทุกชิ้นในงานนั้นจะถูกนำมาเทียบ (แสดงเป็นนิรนามในรายงาน) |
| **เอกสารอ้างอิง** | วางข้อความหรือโค้ดจากหน้าเว็บ หนังสือ เฉลย หรือ**คำตอบจาก AI chatbot** (ลองถามโจทย์กับ ChatGPT/Gemini แล้ววางคำตอบไว้) หรือแนบไฟล์ |
| **✦ คำตอบจาก AI** | ให้ระบบถามโจทย์ของงานนี้กับ AI ให้เอง 3 แบบ แล้วเพิ่มคำตอบเข้าคลัง (ปุ่มนี้ขึ้นเมื่อผู้ดูแลระบบเปิดบริการไว้) |

**เรื่องที่ควรรู้เกี่ยวกับคำตอบจาก AI**
- ใช้ "คำสั่งงาน" เป็นโจทย์ จึงต้องเขียนคำสั่งงานให้ครบก่อน
- ระบบส่งออกไปเฉพาะชื่องาน คำสั่งงาน และข้อความตั้งต้น **ไม่ส่งงานของ นนอ.**
- **ไม่ใช่การตรวจว่างานเขียนด้วย AI** แชตบอตตอบไม่ซ้ำคำเดิมทุกครั้ง จึงจับโค้ดและข้อความมาตรฐาน (นิยาม สูตร) ได้ดีกว่าเรียงความมาก งานที่ไม่ตรงกับคำตอบเหล่านี้ไม่ได้แปลว่าไม่ได้ใช้ AI
- กดซ้ำได้เพื่อเพิ่มคำตอบอีกชุด (งานหนึ่งมีได้ไม่เกิน 9 คำตอบ) แต่ละครั้งมีค่าใช้จ่ายของสถาบัน
- คำตอบแต่ละรายการขึ้นต้นด้วย "AI ·" และนำออกได้เหมือนแหล่งอ้างอิงอื่น

กด **เพิ่มและตรวจใหม่** ระบบตรวจงานทุกชิ้นใหม่ทันที และแสดงว่าแหล่งนั้นตรงกับงานกี่คน กด **นำออก** เพื่อลบแหล่ง

## 7. แบบทดสอบ

### 7.1 สร้างแบบทดสอบ

แท็บ **แบบทดสอบ** → **สร้างแบบทดสอบ**

| ช่อง | คำอธิบาย |
|---|---|
| ชื่อแบบทดสอบ / คำชี้แจง | |
| เปิดสอบ / ปิดสอบ | เวลาประเทศไทย นนอ. เริ่มทำได้ทุกเวลาในช่วงนี้ |
| เวลาทำ (นาที) | นับจากที่ นนอ. กดเริ่ม และไม่เกินเวลาปิดสอบ เว้นว่าง = ทำได้จนถึงเวลาปิดสอบ |
| สุ่มลำดับข้อให้แต่ละคน / สุ่มลำดับตัวเลือก | |
| หลังปิดสอบ นนอ. เห็น | **ไม่เห็นอะไร / คะแนนของตัวเอง / คะแนน คำตอบ และความเห็นจากอาจารย์** |
| ทำแบบทดสอบได้จากที่ไหน | **ที่ไหนก็ได้** หรือ **เฉพาะห้องสอบที่เลือก** (ห้องสอบตั้งโดยผู้ดูแลระบบ) |
| ให้ นนอ. เห็น | เผยแพร่ (ต้องมีข้อสอบอย่างน้อย 1 ข้อ) |

แท็บ **แบบทดสอบ** แสดงแบบทดสอบเป็นการ์ด แต่ละการ์ดมี 2 ปุ่ม: **ข้อสอบ** (แก้ข้อสอบและการตั้งค่า) และ **ผลสอบ** (พร้อมจำนวนที่เริ่มทำแล้ว เช่น 1/5) ในหน้าแบบทดสอบก็มีแท็บใหญ่ **ข้อสอบ | ผลสอบ** ใต้ชื่อแบบทดสอบเช่นกัน

### 7.2 เพิ่มข้อสอบ

แท็บ **ข้อสอบ** → **เพิ่มข้อสอบ** → เลือก **ประเภท**

| ประเภท | สิ่งที่ต้องใส่ | การตรวจ |
|---|---|---|
| ปรนัย (ตอบข้อเดียว) | ตัวเลือก ≥ 2 ข้อ ติ๊กข้อที่ถูก 1 ข้อ (ปุ่ม **ถูก / ผิด** สร้างตัวเลือกให้ในคลิกเดียว) | อัตโนมัติ |
| ปรนัย (ตอบได้หลายข้อ) | ติ๊กทุกข้อที่ถูก | อัตโนมัติ ให้คะแนนบางส่วน = (เลือกถูก − เลือกผิด) ÷ จำนวนข้อที่ถูก ไม่ติดลบ |
| คำตอบสั้น | **คำตอบที่ยอมรับ** บรรทัดละหนึ่งคำตอบ | ตรงกัน (ไม่สนตัวพิมพ์และช่องว่าง) = อัตโนมัติ ไม่ตรง = อาจารย์ตรวจ |
| อัตนัย / เขียนโค้ด | (ติ๊ก "คำตอบเป็นโค้ด" ถ้าต้องการช่องพิมพ์แบบ monospace) | อาจารย์ตรวจ |
| เขียนโค้ด (รันในเบราว์เซอร์) | **ภาษา** (Python / JavaScript / HTML-CSS-JS) และ **โค้ดเริ่มต้น** (ไม่บังคับ) | อาจารย์ตรวจ |

- เรียงลำดับข้อโดยลาก หรือใช้ปุ่ม **เลื่อนขึ้น / เลื่อนลง**
- **แก้เฉลยหลังมี นนอ. ทำแล้ว:** ระบบคิดคะแนนข้อที่ตรวจอัตโนมัติใหม่ให้ แต่คะแนนที่อาจารย์ให้เองไม่เปลี่ยน
- ข้อสอบโค้ด: นนอ. รันโค้ดในเบราว์เซอร์ของตัวเองได้ ระบบ**ไม่ตรวจโค้ดอัตโนมัติ** อาจารย์รันโค้ดของ นนอ. ดูได้ในหน้าตรวจ

### 7.3 แบบทดสอบเข้าสมุดคะแนน

แบบทดสอบสร้างคอลัมน์ในสมุดคะแนนให้อัตโนมัติ คะแนนของ นนอ. แต่ละคนเข้าสมุดคะแนนเมื่อ**ตรวจครบทุกข้อ** แล้วกด **แสดงให้ นนอ. เห็น** ในสมุดคะแนนเมื่อพร้อมประกาศ

## 8. การคุมสอบ

ระบบใช้**โหมดเต็มจอในเบราว์เซอร์ปกติ** และต้องมีอาจารย์คุมสอบในห้อง

**สิ่งที่ระบบทำ**
- จับเวลาที่เซิร์ฟเวอร์ ส่งคำตอบให้อัตโนมัติเมื่อหมดเวลา
- บันทึกคำตอบอัตโนมัติ ถ้าเน็ตหลุด นนอ. ทำต่อได้
- ไม่ส่งเฉลยไปที่เครื่อง นนอ.
- บล็อก copy / paste / คลิกขวา
- บันทึกเหตุการณ์: **ออกจากหน้าต่างสอบ, สลับแท็บหรือย่อหน้าต่าง, ออกจากโหมดเต็มจอ, คัดลอก/วางข้อความ, เปิดเมนูคลิกขวา, เปิดหน้าสอบอีกครั้ง, ทำต่อจากอุปกรณ์หรือเครือข่ายอื่น**

**สิ่งที่ระบบทำไม่ได้:** กันโทรศัพท์ เครื่องที่สอง หรือการคุยกัน จึงต้องมีผู้คุมสอบ

**ระหว่างสอบ** เปิดแท็บ **ผลสอบ** ด้านบนมีสรุป 4 ช่อง: ส่งแล้ว / กำลังทำ / ยังไม่เริ่ม / รอตรวจ ถัดลงมาเป็นสถานะของแต่ละคนและคอลัมน์ **เหตุการณ์**

**ถ้า นนอ. มีปัญหา (เครื่องเสีย)** เปิดการทำข้อสอบของคนนั้น → **ให้ นนอ. คนนี้ทำใหม่** (ลบคำตอบเดิมทั้งหมด และ นนอ. เริ่มใหม่ได้)

## 9. ตรวจข้อสอบ

การ์ดแบบทดสอบ → **ผลสอบ** (หรือแท็บ **ผลสอบ** ในหน้าแบบทดสอบ)

| วิธี | ใช้เมื่อ |
|---|---|
| **ตรวจทีละข้อ** | ตรวจข้อเดียวกันของทุกคนต่อกัน (เหมือนตรวจกระดาษข้อ 3 ทั้งชั้น) เหมาะกับอัตนัยและโค้ด |
| **ดู** (รายคน) | ดูการทำข้อสอบของ นนอ. หนึ่งคน คำตอบทุกข้อ และ **บันทึกเหตุการณ์** |

- ใส่คะแนนและความเห็น ช่องที่เว้นว่างถือว่ายังไม่ตรวจ
- แก้คะแนนข้อที่ตรวจอัตโนมัติได้
- ข้อเขียนโค้ด: กด **รัน** เพื่อรันโค้ดของ นนอ.
- หัวข้อแสดง **รอตรวจ N** / **ตรวจครบแล้ว**

## 10. สมุดคะแนน

แท็บ **คะแนน** มี 2 แท็บย่อย: **ตารางคะแนน | ตั้งค่าการให้คะแนน**

### 10.1 ตั้งค่าการให้คะแนน (ทำครั้งเดียวต่อวิชา)

1. **หมวดคะแนนและสัดส่วน** เช่น งานระหว่างภาค 40% · สอบกลางภาค 25% · สอบปลายภาค 35% (กดปุ่มแม่แบบเพื่อเริ่มจากค่านี้) สัดส่วนรวมควรเป็น 100%
2. **รายการให้คะแนน (คอลัมน์ในตารางคะแนน)** งานและแบบทดสอบที่มีคะแนนเต็มถูกเพิ่มให้อัตโนมัติ ส่วนการสอบบนกระดาษ แล็บ หรือการนำเสนอ กด **เพิ่มคอลัมน์** แล้วใส่ชื่อ คะแนนเต็ม และหมวด
3. **เกณฑ์ตัดเกรด** ค่าเริ่มต้น A ≥ 80, B+ ≥ 75, B ≥ 70, C+ ≥ 65, C ≥ 60, D+ ≥ 55, D ≥ 50, ต่ำกว่านั้น F แก้แล้วกด **บันทึกเกณฑ์** (หรือ **ใช้ค่าเริ่มต้น**)

ตัวเลือก **ให้ นนอ. เห็นคะแนนรวมและเกรดปัจจุบัน** ปิดได้ถ้าไม่ต้องการให้ นนอ. เห็นเกรดระหว่างภาค

### 10.2 ตารางคะแนน

- พิมพ์คะแนนลงตาราง ระบบคำนวณ **รวม** และ **เกรด** ทันที กด Enter เพื่อเลื่อนลงแถวถัดไป
- ช่องที่แก้แต่ยังไม่บันทึกเป็นสีฟ้า ("ยังไม่บันทึก N ช่อง") กด **บันทึกคะแนน**
- **ช่องว่างไม่ถูกนับ** ถ้า นนอ. ไม่ส่งงาน ให้ใส่ **0**
- ใส่เกินคะแนนเต็มไม่ได้
- **แสดงให้ นนอ. เห็น / ซ่อนจาก นนอ.** ทีละคอลัมน์ นนอ. เห็นเฉพาะคอลัมน์ที่เผยแพร่
- **ดาวน์โหลด CSV** สำหรับส่งงานทะเบียน (เปิดใน Excel ภาษาไทยได้)

> ทุกการแก้คะแนนถูกบันทึกว่าใครแก้ เมื่อไร จากเท่าไรเป็นเท่าไร
>
> **เฉพาะอาจารย์ผู้สอนวิชานั้น**ที่แก้คะแนนได้ ผู้ดูแลระบบดูและดาวน์โหลดได้อย่างเดียว

### 10.3 การคำนวณ

- ในแต่ละหมวด: % = คะแนนที่ได้รวม ÷ คะแนนเต็มรวม (ไม่นับช่องว่าง)
- คะแนนรวม: เฉลี่ยถ่วงน้ำหนักเฉพาะหมวดที่มีคะแนนแล้ว
- ถ้าไม่ตั้งหมวด: คะแนนที่ได้รวม ÷ คะแนนเต็มรวม
- เกรดที่ นนอ. เห็นคิดจาก**คอลัมน์ที่เผยแพร่แล้ว**เท่านั้น

## 11. สอนหลายกลุ่มเรียน

ใช้บัญชีเดียว แต่ละกลุ่มเรียนแยกข้อมูลกัน ป้าย "กลุ่ม N" แสดงเมื่อวิชามีหลายกลุ่ม

"กลุ่มเรียนอื่น" หมายถึงกลุ่มอื่นของ**วิชาเดียวกันในภาคเรียนเดียวกัน**ที่คุณสอน (เช่น CS201 กลุ่ม 2) ปุ่มเหล่านี้จะไม่ขึ้นถ้าวิชามีกลุ่มเดียว

| ต้องการ | ทำอย่างไร |
|---|---|
| สร้างเอกสาร/งานใหม่ให้หลายกลุ่มพร้อมกัน | ในฟอร์มสร้าง ติ๊กกลุ่มที่ต้องการในกรอบ **สร้างในกลุ่มเรียนอื่นด้วย** |
| คัดลอกเอกสารหรืองานที่มีอยู่แล้ว | กด **⧉ คัดลอกไปกลุ่มเรียนอื่น** ที่รายการนั้น |
| ใช้การตั้งค่าคะแนนเดียวกัน | สมุดคะแนน › ตั้งค่าการให้คะแนน › **⧉ คัดลอกไปกลุ่มเรียนอื่น** |

หน้าต่างคัดลอกบอกครบในที่เดียว:

1. **สิ่งที่จะคัดลอก**: ชื่อเอกสารหรืองานที่เลือก
2. **คัดลอกไปที่กลุ่มเรียนใด**: แต่ละกลุ่มแสดงชื่ออาจารย์ผู้สอนและจำนวน นนอ. (ถ้ามีกลุ่มอื่นกลุ่มเดียว ระบบติ๊กไว้ให้)
3. **คัดลอก / ไม่คัดลอก**: รายการว่าอะไรไปด้วยและอะไรไม่ไป

| | คัดลอก | ไม่คัดลอก |
|---|---|---|
| เอกสาร | ชื่อ คำอธิบาย สัปดาห์ ไฟล์หรือลิงก์ สถานะให้ นนอ. เห็น | — |
| งานที่มอบหมาย | ชื่องาน คำสั่งงาน กำหนดส่ง การตั้งค่าตรวจความคล้าย ข้อความตั้งต้น คะแนนเต็มและหมวด | งานที่ นนอ. ส่ง ผลตรวจความคล้าย คะแนน คลังแหล่งอ้างอิง |
| การตั้งค่าการให้คะแนน | หมวดและน้ำหนัก เกณฑ์ตัดเกรด คอลัมน์ที่ไม่ใช่งานหรือแบบทดสอบ | คะแนน และคอลัมน์ของงานหรือแบบทดสอบ |

> แต่ละกลุ่มได้**สำเนาแยกของตัวเอง** ถ้าแก้หรือลบที่กลุ่มนี้ภายหลัง กลุ่มอื่นจะไม่เปลี่ยนตาม และถ้าคัดลอกซ้ำจะได้รายการซ้ำ

## 12. คำถามที่พบบ่อย

**ถาม: นนอ. บอกว่าไม่เห็นงาน/เอกสาร**
ตอบ: ตรวจว่าเปิดสวิตช์ **ให้ นนอ. เห็น** แล้ว และ นนอ. อยู่ในรายชื่อกลุ่มเรียนนี้ (ถ้าไม่อยู่ แจ้งผู้ดูแลระบบ)

**ถาม: นนอ. ลืมรหัสผ่าน**
ตอบ: ให้ติดต่อผู้ดูแลระบบ ซึ่งออกรหัสผ่านชั่วคราวใหม่ให้

**ถาม: อยากให้ นนอ. คนหนึ่งส่งงานหลังปิดรับ**
ตอบ: แก้ไขงานให้รับงานส่งช้า หรือเลื่อนกำหนดส่ง (มีผลกับทุกคน)

**ถาม: งานที่ส่งเป็น PDF ภาษาไทยขึ้นว่า "ไม่ได้ตรวจ"**
ตอบ: PDF ไฟล์นั้นใช้ฟอนต์ไทยที่ดึงข้อความไม่ได้ถูกต้อง ระบบจึงไม่ให้ค่าความคล้ายที่ผิด แนะนำให้ นนอ. ส่งเป็น .docx หรือพิมพ์ในช่องคำตอบ

**ถาม: ความคล้ายสูงเพราะทุกคนคัดลอกโจทย์**
ตอบ: วางโจทย์ไว้ใน **ข้อความตั้งต้นที่ไม่นับ** หรือเปิด **ไม่นับข้อความที่ซ้ำกันเกินครึ่งชั้น** แล้วกด **ตรวจใหม่**

**ถาม: ผมเป็นผู้ดูแลระบบด้วย ทำไมแก้คะแนนวิชาตัวเองไม่ได้**
ตอบ: สิทธิ์แก้คะแนนมาจากการเป็น "อาจารย์ผู้สอน" ในกลุ่มเรียน ให้เพิ่มตัวเองเป็นอาจารย์ในรายชื่อของกลุ่มเรียนนั้น
