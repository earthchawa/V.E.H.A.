# คู่มือการใช้งานสำหรับผู้ดูแลระบบ

คู่มือนี้อธิบายงานของผู้ดูแลระบบในหน้าเว็บ: บัญชีผู้ใช้ ภาคเรียนและรายวิชา ตารางสอน กองวิชา การตั้งค่าการสอบ และประวัติการใช้งาน

> การติดตั้งเซิร์ฟเวอร์ สำรองข้อมูล และอัปเดตเวอร์ชัน ดู [คู่มือการติดตั้งและดูแลระบบ](../technical/operations.md)

**เมนูของผู้ดูแลระบบ** (แถบด้านบน หรือปุ่ม **เมนู** บนมือถือ)

| เมนู | ใช้ทำอะไร |
|---|---|
| **รายวิชา** | หน้าแรก: วิชาทั้งหมดในภาคเรียน เข้าไปจัดการเนื้อหาในห้องเรียนได้ |
| **ผู้ใช้** | สร้าง/นำเข้า/แก้ไขบัญชี รีเซ็ตรหัสผ่าน ปิดใช้งาน |
| **ภาคเรียนและรายวิชา** | ภาคเรียน รายวิชาในหลักสูตร กลุ่มเรียน รายชื่อ นำเข้าตารางสอน |
| **กองวิชา/ภาควิชา** | โครงสร้างหน่วยงาน สีและโลโก้ |
| **ตั้งค่าการสอบ** | ห้องสอบและช่วง IP |
| **ประวัติการใช้งาน** | บันทึกการกระทำในระบบ |
| **ระบบ** | ดาวน์โหลดข้อมูลสำรอง ดูที่เก็บไฟล์ และสถานะบริการเสริม |

## 1. สิทธิ์ของผู้ดูแลระบบ

| ทำได้ | ทำไม่ได้ |
|---|---|
| จัดการบัญชี ภาคเรียน รายวิชา กลุ่มเรียน รายชื่อ กองวิชา การตั้งค่าการสอบ | **แก้คะแนน** ตั้งค่าสมุดคะแนน ตรวจข้อสอบ หรือให้ นนอ. ทำแบบทดสอบใหม่ |
| เข้าทุกห้องเรียน เพิ่ม/แก้เอกสาร งาน แบบทดสอบ คลังแหล่งอ้างอิง | |
| ดูสมุดคะแนน รายงานความคล้าย ผลสอบ และ **ดาวน์โหลด CSV** | |
| ดูและ export ประวัติการใช้งาน | |

คะแนนเป็นความรับผิดชอบของอาจารย์ผู้สอน ถ้าผู้ดูแลระบบสอนวิชาใดด้วย ให้เพิ่มตัวเองเป็น**อาจารย์**ในรายชื่อของกลุ่มเรียนนั้น จึงจะแก้คะแนนวิชานั้นได้

## 2. บัญชีผู้ใช้

เมนู **ผู้ใช้** แสดงบัญชีแยกตามแท็บ **ทั้งหมด / นนอ. / อาจารย์ / ผู้ดูแลระบบ** จัดกลุ่มตามกองวิชา/ภาควิชา และมีช่อง**ค้นหา username หรือชื่อ** ตัวกรองกองวิชา และตัวกรอง**ชั้นปี** (กรองทันทีขณะพิมพ์) แท็บ นนอ. มีคอลัมน์ **ชั้นปี** ของปีการศึกษาปัจจุบัน

### 2.1 รูปแบบ username

| ผู้ใช้ | username | ตัวอย่าง (สมมติ) |
|---|---|---|
| นนอ. | เลขประจำตัว นนอ. | `7701` |
| อาจารย์/บุคลากร | ชื่อภาษาอังกฤษ_อักษรแรกของนามสกุล | `somchai_k` |

ใช้ได้เฉพาะตัวอักษรอังกฤษ ตัวเลข และ `._-` ยาว 3–32 ตัว ใส่ยศหรือตำแหน่งวิชาการไว้ในช่อง **ชื่อ-นามสกุล** (แสดงทุกที่ในระบบ)

### 2.2 สถานะบัญชี

| สถานะ | ความหมาย | ทำอย่างไร |
|---|---|---|
| ใช้งาน | ปกติ | |
| ยังไม่เคยเข้าระบบ | ยังใช้รหัสผ่านเริ่มต้นอยู่ | |
| รหัสผ่านเริ่มต้นหมดอายุ | ไม่ได้เข้าระบบภายใน 14 วัน | **รีเซ็ตรหัสผ่าน** |
| ล็อกชั่วคราว | ใส่รหัสผิด 5 ครั้ง (ล็อก 15 นาที) | รอ หรือ **รีเซ็ตรหัสผ่าน** |
| ปิดใช้งาน | ผู้ดูแลปิดไว้ | **เปิดใช้งาน** ถ้าต้องการ |

### 2.3 สร้างบัญชีทีละคน

**สร้างบัญชีใหม่** → ใส่ username, ชื่อ-นามสกุล, บทบาท, กองวิชา/ภาควิชา, ชั้นปี (เฉพาะ นนอ.), อีเมล (ไม่บังคับ) → **สร้างบัญชี**

ระบบแสดง**รหัสผ่านชั่วคราวครั้งเดียว** จดหรือกด **ดาวน์โหลด CSV** ก่อนปิดหน้าต่าง

### 2.4 นำเข้าจาก CSV (ทั้งชั้นปี)

**นำเข้าจาก CSV** → ลากไฟล์มาวาง หรือวางข้อมูลในช่อง → **นำเข้า**

```csv
username,fullName,role,email,department,password,year
7701,นนอ.สมมติ ทดสอบ,cadet,,CS,,2
somchai_k,น.ต.สมชาย ตัวอย่าง,instructor,somchai@example.ac.th,CS,,
```

| คอลัมน์ | บังคับ | ค่า |
|---|:-:|---|
| `username` | ✅ | เลขประจำตัว / username |
| `fullName` | ✅ | ชื่อที่แสดงในระบบ |
| `role` | | `cadet` / `instructor` / `admin` (หรือ `นนอ.` / `อาจารย์` / `ผู้ดูแลระบบ`) เว้นว่าง = นนอ. |
| `email` | | ห้ามซ้ำกับบัญชีอื่น |
| `department` | | รหัสภาควิชา เช่น `CS`, `MA`, `SS` (ต้องมีอยู่ในเมนูกองวิชา/ภาควิชา) |
| `password` | | รหัสผ่านเริ่มต้น (อย่างน้อย 6 ตัว) ถ้าเว้นว่าง ระบบสุ่มให้รายคน |
| `year` | | ชั้นปี 1–5 (เฉพาะ นนอ.) บันทึกเป็นชั้นปีของปีการศึกษาปัจจุบัน |

- แถวแรกเป็นหัวตารางได้ ไฟล์ Excel ให้ "Save As → CSV UTF-8"
- บัญชีที่**มีอยู่แล้วจะข้าม** ไม่เขียนทับ ระบบแจ้งรายการที่ข้ามพร้อมเหตุผล
- ข้อยกเว้นเดียว: ถ้าไฟล์มีคอลัมน์ `year` ระบบจะ**ตั้งชั้นปีให้ นนอ. ที่มีบัญชีอยู่แล้ว** (ไม่แตะข้อมูลอื่น) จึงใช้ไฟล์รายชื่อเดิมที่เติมคอลัมน์ `year` เพื่อใส่ชั้นปีย้อนหลังทั้งรุ่นได้
- หลังนำเข้า ระบบแสดงตารางรหัสผ่านชั่วคราว **แสดงครั้งเดียว** กด **ดาวน์โหลด CSV** เพื่อพิมพ์แจกรายบุคคล
- ทุกคนต้องเปลี่ยนรหัสผ่านเมื่อเข้าครั้งแรก ไม่ว่ารหัสเริ่มต้นจะมาจากไฟล์หรือระบบสุ่ม

> **แนะนำ:** ปล่อยคอลัมน์ `password` ว่างให้ระบบสุ่มรายคน ถ้าทุกคนใช้รหัสเริ่มต้นเดียวกัน ใครที่รู้เลขประจำตัวของเพื่อนจะเข้าบัญชีที่เจ้าของยังไม่เคยเข้าได้
>
> ⚠️ ไฟล์รายชื่อและใบรหัสผ่านเป็นข้อมูลส่วนบุคคล ลบจากเครื่องหลังนำเข้า และทำลายใบรหัสหลังแจก

### 2.5 จัดการบัญชี

กด **จัดการ** ท้ายแถว เปิดหน้าต่างเดียวที่ทำได้ทุกอย่าง

| ส่วน | ทำอะไร |
|---|---|
| แก้ไขข้อมูล | username, ชื่อ-นามสกุล, บทบาท, อีเมล, กองวิชา/ภาควิชา, ชั้นปีของปีการศึกษาปัจจุบัน (นนอ.) → **บันทึกการแก้ไข** (บันทึกค่าเดิม→ค่าใหม่ในประวัติ) |
| ประวัติชั้นปี | นนอ. แต่ละนายมีรายการชั้นปีแยกตามปีการศึกษา เช่น 2568 · ชั้นปีที่ 1, 2569 · ชั้นปีที่ 2 |
| **รีเซ็ตรหัสผ่าน** | ออกรหัสชั่วคราวใหม่ รหัสเดิมใช้ไม่ได้ทันที และผู้ใช้ถูกออกจากระบบทุกเครื่อง |
| **ปิดใช้งาน / เปิดใช้งาน** | ปิดแล้วผู้ใช้ถูกออกจากระบบทันทีและเข้าไม่ได้ **งานและคะแนนไม่ถูกลบ** |

- เปลี่ยนบทบาทของตัวเองไม่ได้ (กันการล็อกตัวเองออกจากหน้าผู้ดูแล)
- ระบบ**ไม่มีการลบบัญชี** ใช้ปิดใช้งานแทน เพื่อเก็บประวัติงานและคะแนน

### 2.6 ชั้นปีและการเลื่อนชั้น

ระบบเก็บชั้นปีของ นนอ. **แยกตามปีการศึกษา** การเลื่อนชั้นจึงเป็นการเพิ่มรายการของปีใหม่ ไม่ได้เขียนทับของเดิม ประวัติทุกปีของแต่ละนายยังอยู่

**ใส่ชั้นปีครั้งแรก:** ใส่ในคอลัมน์ `year` ตอนนำเข้า (ข้อ 2.4) หรือแก้รายคนที่ปุ่ม **จัดการ**

**เลื่อนชั้นตอนสิ้นปีการศึกษา:** หน้าผู้ใช้ → **เลื่อนชั้นปี**

1. เลือกปีการศึกษา เช่น 2569 → 2570
2. เลือก **ชั้นปีสุดท้าย** (ค่าเริ่มต้นชั้นปีที่ 4) นนอ. ชั้นปีนี้จะสำเร็จการศึกษาแทนการเลื่อนชั้น
3. ตรวจตารางสรุป: แต่ละชั้นปีมีกี่นาย และจะไปชั้นปีใด
4. ถ้าต้องการ เปิดสวิตช์ **ปิดใช้งานบัญชีของผู้สำเร็จการศึกษา** (งานและคะแนนยังอยู่)
5. กด **เลื่อนชั้นเข้าปีการศึกษา …**

- เลื่อนเฉพาะ นนอ. ที่บัญชียังใช้งานอยู่และมีชั้นปีในปีการศึกษาที่เลือก
- กดซ้ำได้: นนอ. ที่มีข้อมูลของปีใหม่อยู่แล้วจะไม่ถูกแก้
- กรณีรายบุคคล เช่น ซ้ำชั้น ให้แก้หลังเลื่อนชั้นที่ปุ่ม **จัดการ**
- คอลัมน์และตัวกรองชั้นปีในหน้าผู้ใช้แสดงตาม**ปีการศึกษาของภาคเรียนปัจจุบัน** หลังเลื่อนชั้นแล้วจึงยังเห็นชั้นปีเดิมจนกว่าจะตั้งภาคเรียนของปีใหม่เป็นภาคปัจจุบัน

### 2.7 เมื่อผู้ใช้ลืมรหัสผ่าน

ตอนนี้หน้า **ลืมรหัสผ่าน?** แจ้งให้ผู้ใช้ติดต่อผู้ดูแลระบบ

1. ยืนยันตัวตนผู้ขอ (เช่น ให้มาด้วยตัวเองหรือติดต่อผ่านช่องทางของหน่วย)
2. **ผู้ใช้** → ค้นหา → **จัดการ** → **รีเซ็ตรหัสผ่าน**
3. แจ้งรหัสชั่วคราวให้ผู้ใช้โดยตรง ผู้ใช้ต้องตั้งรหัสใหม่เมื่อเข้าระบบ

> ถ้าฝ่าย IT ตั้งค่าเซิร์ฟเวอร์อีเมล (SMTP) ในอนาคต ปุ่ม "ลืมรหัสผ่าน?" จะส่งลิงก์รีเซ็ตทางอีเมลให้ผู้ใช้ที่ใส่อีเมลไว้

## 3. ภาคเรียนและรายวิชา

เมนู **ภาคเรียนและรายวิชา** มี 2 แท็บ

### 3.1 แท็บภาคเรียน

- ปุ่มภาคเรียนด้านบน ป้าย **ปัจจุบัน** = ภาคที่หน้าแรกแสดงเป็นค่าเริ่มต้น, ป้าย **ภาคถัดไป** = ภาคที่ใหม่กว่า
- เลือกภาค → เห็นกลุ่มเรียนทั้งหมด จัดกลุ่มตามภาควิชา แต่ละแถวแสดงอาจารย์ผู้สอน (หรือ "ยังไม่มีอาจารย์ผู้สอน" สีส้ม) และจำนวน นนอ.
- **ตั้งเป็นภาคเรียนปัจจุบัน**: กดเมื่อเปิดภาคใหม่
- **+ เปิดสอนวิชาในภาคนี้**: สร้างกลุ่มเรียนทีละกลุ่ม (เลือกวิชา ภาค และหมายเลขกลุ่ม)
- **จัดการรายชื่อ**: ดู [ข้อ 5](#5-จัดการรายชื่อในกลุ่มเรียน)

ปุ่มด้านบน:
- **เพิ่มภาคเรียน**: ปีการศึกษา (พ.ศ.) และภาค (1, 2 หรือฤดูร้อน)
- **เพิ่มรายวิชา**: รหัสวิชา ชื่อวิชาอังกฤษ/ไทย หน่วยกิต คำอธิบาย ภาควิชา
- **นำเข้าตารางสอน**: ดู [ข้อ 4](#4-นำเข้าตารางสอน)

### 3.2 แท็บรายวิชาทั้งหมด

รายการวิชาในหลักสูตร (ไม่ขึ้นกับภาคเรียน) จัดกลุ่มตามภาควิชา

- เปลี่ยนภาควิชาของวิชาจาก dropdown ในแถวได้ทันที
- **แก้ไข**: แก้รหัสวิชา ชื่อ หน่วยกิต คำอธิบาย (การแก้มีผลกับทุกภาคเรียนที่เปิดวิชานี้)

> รายวิชาในหลักสูตร CS และ MA ถูกสร้างไว้ให้แล้ว วิชาของกองวิชาอื่นเพิ่มเองผ่าน **เพิ่มรายวิชา** หรือนำเข้าตารางสอน

## 4. นำเข้าตารางสอน

วิธีที่เร็วที่สุดในการตั้งค่าภาคเรียนใหม่: ไฟล์เดียวสร้างภาคเรียน รายวิชา กลุ่มเรียน และลงทะเบียนอาจารย์กับ นนอ.

**ภาคเรียนและรายวิชา** → **นำเข้าตารางสอน** → ลากไฟล์ CSV มาวาง หรือวางข้อมูล → **นำเข้า**

```csv
year,semester,code,title_th,title_en,credits,section,instructors,cadets
2569,1,คต 231,โครงสร้างข้อมูล,Data Structures,3,1,somchai_k,7701 7702 7703
2569,1,CS232,,,3,1,somchai_k malee_s,7701 7702 7703
2569,2,ศส402,สังคมศาสตร์ 5,Social Science 5,3,2,anong_p,7801 7802
```

| คอลัมน์ | ความหมาย |
|---|---|
| `year` | ปีการศึกษา พ.ศ. |
| `semester` | 1, 2 หรือ 3 (ฤดูร้อน) |
| `code` | รหัสวิชา ไทยหรืออังกฤษ (`คต 231` = `CS231`, `คณ`→MA, `ฟส`→PH, `คม`→CH, `สศ`/`ศส`→SS) |
| `title_th`, `title_en`, `credits` | ใช้เฉพาะวิชาที่ยังไม่มีในระบบ (วิชาที่มีแล้วเว้นว่างได้) |
| `section` | หมายเลขกลุ่มเรียน (เว้นว่าง = 1) |
| `instructors` | username ของอาจารย์ผู้สอน คั่นด้วยช่องว่าง (บังคับ) |
| `cadets` | เลขประจำตัว นนอ. คั่นด้วยช่องว่าง (ไม่บังคับ) |

**ลำดับที่ถูกต้อง:** นำเข้าบัญชีอาจารย์และ นนอ. ก่อน (ข้อ 2.4) แล้วจึงนำเข้าตารางสอน ถ้าในไฟล์มี username ที่ยังไม่มีบัญชี ระบบ**ไม่นำเข้าทั้งไฟล์**และแจ้งรายชื่อที่ขาด

**นำเข้าซ้ำได้อย่างปลอดภัย:** ระบบสร้างเฉพาะสิ่งที่ยังไม่มี และ**ไม่แก้หรือลบข้อมูลเดิม** จึงใช้เพิ่มอาจารย์หรือ นนอ. ภายหลังได้ แต่ถ้าต้องการ**เปลี่ยน**รหัสหรือชื่อวิชาที่นำเข้าไปแล้ว ให้แก้ที่แท็บรายวิชาทั้งหมด › **แก้ไข** (นำเข้าไฟล์ที่ใช้รหัสใหม่จะได้วิชาซ้ำสองวิชา)

## 5. จัดการรายชื่อในกลุ่มเรียน

**ภาคเรียนและรายวิชา** → เลือกภาค → **จัดการรายชื่อ** ของกลุ่มเรียน

- **เพิ่มรายชื่อ**: เลือก **เพิ่มเป็น** อาจารย์หรือ นนอ. แล้วใส่รหัสประจำตัว (คั่นด้วยเว้นวรรค จุลภาค หรือขึ้นบรรทัดใหม่) → **เพิ่ม**
- **นำออก**: เอาออกจากกลุ่มเรียน ระบบถามยืนยันก่อน (งานที่ส่งแล้วยังอยู่ในฐานข้อมูล)
- **ไปหน้าวิชา**: เปิดห้องเรียนของกลุ่มนี้

บัญชี นนอ. เพิ่มเป็นอาจารย์ไม่ได้

### ลบกลุ่มเรียน

ด้านล่างของหน้าจัดการรายชื่อมีปุ่ม **ลบกลุ่มเรียนนี้** ใช้เมื่อเปิดกลุ่มเรียนผิด

- หน้าต่างยืนยันแสดงจำนวนสิ่งที่จะถูกลบ: รายชื่อ เอกสาร งานที่มอบหมาย งานที่ส่ง แบบทดสอบ และคอลัมน์คะแนน
- ต้อง**พิมพ์รหัสวิชา** (เช่น CS201) เพื่อยืนยัน แล้วกด **ลบกลุ่มเรียนนี้ถาวร**
- ⚠️ ลบแล้ว**กู้คืนไม่ได้** รวมถึงงานและคะแนนของ นนอ. ในกลุ่มนั้น ถ้ากลุ่มเรียนมีข้อมูลจริงแล้ว ควรสำรองข้อมูลก่อน
- ไม่ลบ: รายวิชาในหลักสูตร ภาคเรียน บัญชีผู้ใช้ และกลุ่มเรียนอื่น
- การลบถูกบันทึกในประวัติการใช้งาน

## 6. กองวิชาและภาควิชา

เมนู **กองวิชา/ภาควิชา** — โครงสร้าง 2 ระดับ: **กองวิชา** (เช่น MC กองวิชาคณิตศาสตร์และคอมพิวเตอร์) → **ภาควิชา** (เช่น CS ภาควิชาคอมพิวเตอร์, MA ภาควิชาคณิตศาสตร์)

- **เพิ่มกองวิชาหรือภาควิชา**: รหัส (A-Z, 0-9, `-` ไม่เกิน 16 ตัว), ชื่ออังกฤษ ("Department of …"), ชื่อไทย, **สังกัดกองวิชา** (เลือก "ไม่มี" = เป็นกองวิชา)
- **สีประจำ** และ **โลโก้** (PNG/JPG/WebP ไม่เกิน 1 MB ภาพสี่เหลี่ยมจัตุรัส) ภาควิชาที่ไม่ได้ตั้งจะใช้สี/โลโก้ของกองวิชา สีนี้ใช้กับการ์ดวิชาและป้ายทั่วระบบ
- ลบหน่วย: รายวิชาและบุคลากรในหน่วยนั้นกลายเป็น "ไม่ระบุกองวิชา" ลบกองวิชาที่ยังมีภาควิชาอยู่ไม่ได้

## 7. ตั้งค่าการสอบ

เมนู **ตั้งค่าการสอบ** — ตั้งครั้งเดียวใช้ทั้งสถาบัน อาจารย์แค่เลือกห้องตอนสร้างแบบทดสอบ

**ห้องสอบ** → **เพิ่มห้อง**: ใส่ชื่อห้อง และที่อยู่เครือข่าย (IP หรือ CIDR บรรทัดละหนึ่งรายการ เช่น `10.20.30.0/24`) ขอช่วง IP ของ Wi-Fi/LAN ในห้องจากฝ่าย IT

- หน้านี้แสดง **IP ของคุณตอนนี้** ใช้ตรวจว่าระบบเห็น IP ของเครื่องในห้องสอบถูกต้อง (ลองเปิดจากเครื่องในห้องสอบจริง)
- แบบทดสอบที่จำกัดห้อง: นนอ. ที่ใช้เน็ตมือถือหรือ Wi-Fi อื่นจะเริ่มทำไม่ได้
- รูปแบบการสอบปัจจุบัน: **เบราว์เซอร์แบบเต็มจอ** + อาจารย์คุมสอบ (โหมด Safe Exam Browser ปิดไว้)

## 8. ประวัติการใช้งาน

เมนู **ประวัติการใช้งาน** — บันทึกว่าใครทำอะไร เมื่อไร จาก IP ใด จัดกลุ่มตามวัน

**หมวด** (ปุ่มด้านบน พร้อมจำนวน): เข้าสู่ระบบและรหัสผ่าน · ผู้ใช้และการลงทะเบียน · รายวิชาและเอกสาร · งานที่มอบหมาย · แบบทดสอบ · คะแนน · ตั้งค่าระบบ

**ตัวกรอง**: ค้นหาข้อความ, กองวิชา, ช่วงวันที่ (หรือปุ่ม วันนี้ / 7 วัน / 30 วัน), **เฉพาะปัญหา** (เข้าระบบไม่สำเร็จ ถูกล็อก) → **กรอง** ลิงก์ของหน้าที่กรองแล้วส่งต่อให้ผู้อื่นได้

**Export CSV**: ดาวน์โหลดตามตัวกรองที่เลือก (เปิดใน Excel ภาษาไทยได้)

ตัวอย่างการใช้งาน:
- ใครแก้คะแนนวิชา X → หมวด **คะแนน** + ค้นหารหัสวิชา (รายละเอียดแสดงค่าเดิม→ค่าใหม่)
- มีคนพยายามเดารหัสผ่านไหม → ติ๊ก **เฉพาะปัญหา**
- ใครเปลี่ยนบทบาทของบัญชีหนึ่ง → หมวด **ผู้ใช้และการลงทะเบียน** + ค้นหา username

> กองวิชา = กองวิชาของรายวิชานั้น ส่วนการเข้าสู่ระบบและบัญชีผู้ใช้นับตามกองวิชาของผู้ใช้

## 8.5 ระบบ: สำรองข้อมูลและที่เก็บไฟล์

เมนู **ระบบ**

### สำรองข้อมูล

| ปุ่ม | ได้อะไร |
|---|---|
| **ฐานข้อมูล › ดาวน์โหลด** | บัญชีผู้ใช้ รายวิชา งานและข้อความที่ส่ง แบบทดสอบ คะแนน และประวัติการใช้งาน เป็นไฟล์เดียว |
| **ไฟล์ที่อัปโหลด › ดาวน์โหลด** | เอกสาร ไฟล์งานที่ส่ง และโลโก้ รวมเป็นไฟล์เดียว (ปุ่มนี้ขึ้นเมื่อมีไฟล์) |

- แนะนำให้ดาวน์โหลด**ทั้งสองไฟล์**อย่างน้อยสัปดาห์ละครั้ง และก่อนงานสำคัญ เช่น ก่อนเลื่อนชั้นปี ก่อนลบกลุ่มเรียน
- เก็บไฟล์ไว้นอกเครื่องที่ใช้ประจำ เช่น ฮาร์ดดิสก์ของหน่วยที่ล็อกได้
- ⚠️ ไฟล์สำรองมีข้อมูลส่วนบุคคล คะแนน และรหัสผ่านที่เข้ารหัสแล้วของทุกคน **ห้ามส่งทางอีเมลหรือแชต**
- หน้านี้แสดงวันที่ดาวน์โหลดล่าสุด และทุกการดาวน์โหลดถูกบันทึกในประวัติการใช้งาน
- การ**กู้คืน**ทำโดยฝ่าย IT บนเซิร์ฟเวอร์ (ดูคู่มือการติดตั้งและดูแลระบบ ข้อ 4)

### ที่เก็บไฟล์

แสดงว่าไฟล์ใหม่เก็บที่ใด ขนาดอัปโหลดสูงสุด จำนวนและขนาดไฟล์ทั้งหมด และขนาดฐานข้อมูล

- ถ้าระบบอยู่บน Vercel และยังเก็บไฟล์ในฐานข้อมูล (อัปโหลดได้ไม่เกิน 4 MB) หน้านี้จะบอกวิธีเชื่อม Vercel Blob
- หลังเชื่อม Blob แล้ว ถ้ามีไฟล์เดิมค้างในฐานข้อมูล จะมีปุ่ม **ย้ายไฟล์เหล่านี้ไป Blob** กดซ้ำได้จนไม่เหลือ (ควรดาวน์โหลดข้อมูลสำรองก่อน)

### บริการเสริม

แสดงสถานะ เปิดใช้ / ยังไม่เปิด ของ: ที่เก็บไฟล์ Vercel Blob, สร้างคำตอบ AI สำหรับเทียบ, รีเซ็ตรหัสผ่านทางอีเมล การเปิดแต่ละอย่างทำโดยฝ่าย IT ผ่านการตั้งค่าของเซิร์ฟเวอร์

## 9. งานตามรอบภาคเรียน

### ก่อนเปิดภาค (2–4 สัปดาห์)

1. ขอให้ฝ่าย IT สำรองข้อมูล
2. **นำเข้าบัญชี** นนอ. ชั้นปีใหม่และอาจารย์ใหม่ (ข้อ 2.4) แจกใบรหัสผ่าน
3. **นำเข้าตารางสอน** ของภาคใหม่ (ข้อ 4) ภาคใหม่จะขึ้นเป็น "ภาคถัดไป" และอาจารย์เห็นแถบ "เตรียมเนื้อหาล่วงหน้า" บนหน้าแรก
4. ตรวจกลุ่มเรียนที่ **ยังไม่มีอาจารย์ผู้สอน**

### วันเปิดภาค

5. **ตั้งเป็นภาคเรียนปัจจุบัน**

### ขึ้นปีการศึกษาใหม่

1. กด **เลื่อนชั้นปี** ที่หน้าผู้ใช้ (ข้อ 2.6) ชั้นปีของปีเก่ายังเก็บไว้เป็นประวัติ
2. นำเข้าบัญชี นนอ. ชั้นปีที่ 1 รุ่นใหม่ พร้อมคอลัมน์ `year`
3. นำเข้าตารางสอนภาคใหม่พร้อมรายชื่อ แล้วตั้งเป็นภาคเรียนปัจจุบันเมื่อเปิดภาค

บัญชี นนอ. ใช้ต่อได้เลย ไม่ต้องสร้างใหม่ ประวัติภาคเก่ายังเปิดดูได้ และงานรุ่นก่อนใช้เป็นแหล่งอ้างอิงตรวจความคล้ายได้

### ปลายภาค / สำเร็จการศึกษา

6. ตรวจว่าอาจารย์ส่งคะแนนครบ (เปิดสมุดคะแนนของแต่ละวิชาดูได้)
7. **ปิดใช้งาน** บัญชีผู้สำเร็จการศึกษาและบุคลากรที่ย้ายออก (ข้อมูลไม่ถูกลบ)

## 10. คำถามที่พบบ่อย

**ถาม: นำเข้าตารางสอนไม่ผ่าน "ยังไม่มีบัญชีของ …"**
ตอบ: นำเข้าบัญชีของคนเหล่านั้นก่อน แล้วนำเข้าตารางสอนใหม่ (ไฟล์เดิมได้เลย)

**ถาม: นำเข้าตารางสอนแล้ว รหัสวิชาผิด**
ตอบ: ภาคเรียนและรายวิชา › รายวิชาทั้งหมด › **แก้ไข** อย่านำเข้าไฟล์ที่แก้แล้วซ้ำ เพราะจะได้วิชาใหม่อีกวิชา

**ถาม: อาจารย์ย้ายภาควิชา**
ตอบ: ผู้ใช้ › **จัดการ** › เปลี่ยนกองวิชา/ภาควิชา

**ถาม: นนอ. ไม่เห็นวิชา**
ตอบ: ตรวจว่ามีชื่อใน **จัดการรายชื่อ** ของกลุ่มเรียนนั้น และภาคเรียนที่ นนอ. ดูอยู่ถูกต้อง

**ถาม: อยากให้อาจารย์คนหนึ่งช่วยตรวจคะแนนวิชาอื่น**
ตอบ: เพิ่มเป็น **อาจารย์** ในรายชื่อของกลุ่มเรียนนั้น (ได้สิทธิ์เต็มเหมือนอาจารย์ผู้สอน)

**ถาม: บัญชีผู้ดูแลระบบคนเดียวถูกล็อก**
ตอบ: รอ 15 นาที ถ้าลืมรหัส ให้ผู้ดูแลระบบอีกคนรีเซ็ตให้ ควรมีผู้ดูแลระบบอย่างน้อย 2 บัญชี (ถ้าไม่มีใครเข้าได้เลย ฝ่าย IT สร้างบัญชีผู้ดูแลระบบใหม่บนเซิร์ฟเวอร์ได้: ตั้ง `SEED_ADMIN_USERNAME` เป็นชื่อที่ยังไม่มีในระบบ แล้วรัน `npx tsx prisma/seed.ts` ระบบจะแสดงรหัสผ่านชั่วคราวของบัญชีใหม่ จากนั้นใช้บัญชีนั้นรีเซ็ตรหัสของบัญชีเดิม)
