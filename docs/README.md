# เอกสารระบบ V.E.H.A.

**V.E.H.A.** (Virtual Educational Hangar for Air-cadets) ระบบห้องเรียนออนไลน์ของโรงเรียนนายเรืออากาศนวมินทกษัตริยาธิราช (รร.นอ.)

เอกสารแบ่งเป็น 2 กลุ่มตามผู้อ่าน

## คู่มือผู้ใช้ (User Manual)

สำหรับผู้ใช้งานระบบ ไม่ต้องมีความรู้ด้านโปรแกรม

| เอกสาร | สำหรับ | เนื้อหา |
|---|---|---|
| [manual/cadet.md](manual/cadet.md) | นักเรียนนายเรืออากาศ (นนอ.) | เข้าสู่ระบบ, ดูเอกสาร, ส่งงาน, รายงานความคล้าย, ทำแบบทดสอบ, ดูคะแนน |
| [manual/instructor.md](manual/instructor.md) | อาจารย์ผู้สอน | เอกสาร, สร้างงาน, ตรวจความคล้าย, คลังแหล่งอ้างอิง, แบบทดสอบและการคุมสอบ, สมุดคะแนน |
| [manual/admin.md](manual/admin.md) | ผู้ดูแลระบบ | บัญชีผู้ใช้, นำเข้า CSV, ภาคเรียนและรายวิชา, ตารางสอน, กองวิชา, ประวัติการใช้งาน, งานต้นปีการศึกษา |

## เอกสารทางเทคนิค (Technical Documentation)

สำหรับนักพัฒนาและผู้ดูแลเซิร์ฟเวอร์

| เอกสาร | เนื้อหา |
|---|---|
| [technical/software-design.md](technical/software-design.md) | Software Design Document: ขอบเขต, ความต้องการ, สถาปัตยกรรม, แบบจำลองข้อมูล, การออกแบบแต่ละโมดูล, ความปลอดภัย, ข้อจำกัด |
| [technical/operations.md](technical/operations.md) | การติดตั้ง (Docker / Vercel), ตัวแปรสภาพแวดล้อม, migration, สำรองข้อมูล, อัปเดตเวอร์ชัน, แก้ปัญหา |
| [technical/development.md](technical/development.md) | ตั้งค่าเครื่องนักพัฒนา, โครงสร้างโค้ด, ข้อตกลงในการเขียนโค้ด, การทดสอบ (unit + e2e), ขั้นตอนเพิ่มฟีเจอร์ |

## หลักการดูแลเอกสาร

- เอกสารอยู่ใน repo เดียวกับโค้ด แก้หน้าจอหรือขั้นตอนการใช้งานเมื่อไร ให้แก้คู่มือใน commit เดียวกัน
- คู่มือใช้**ชื่อปุ่มและเมนูตามที่แสดงในระบบภาษาไทย** (มาจาก `src/lib/i18n/th.ts`) ถ้าเปลี่ยนข้อความในระบบ ให้ค้นหาข้อความเดิมใน `docs/` แล้วแก้ตาม
- ห้ามใส่ชื่อ เลขประจำตัว หรือรหัสผ่านของบุคคลจริงในเอกสาร ตัวอย่างทั้งหมดเป็นข้อมูลสมมติ
